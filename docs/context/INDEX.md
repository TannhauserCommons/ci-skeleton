# Context index

Curated pages for what is expensive to rediscover: boundaries, contracts, invariants. Code and tests outrank these pages.

| Task | Read | Then open |
| --- | --- | --- |
| Change a shared script or a task name, or see what a project must fill in | [contract](contract.md) | `.github/ci/tasks.toml`, the script in `.github/ci/` |
| Change the gate, a trigger or a permission | [contract](contract.md) | `.github/workflows/check.yml` |
| Copy the skeleton into a project | `README.md` | `.github/`, `mise.toml`, `switches.toml` |
